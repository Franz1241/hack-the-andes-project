# References

Visual reference and inspiration material for the team. Nothing in this folder is part of the product, is not built, linted or deployed, and is not a pnpm workspace member.

- `peru-simulator/`: standalone Vite prototype (3D Peru terrain, weather and cloud overlays). Snapshot of the `feat/peru-3d-terrain` branch of the separate `peru-simulator` repository. Run it on its own with `npm install && npm run dev` inside the folder.
